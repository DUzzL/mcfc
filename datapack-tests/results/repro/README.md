# Diagnostic and repro runs

Runs made while tracking down single findings, with earlier mcfc builds (the jar is named in each file). They are not part of the final pass in `_summary.md` and not in `../REPORT.md`'s pack table.

- `resetall`, `dynscale`: minimal packs built by hand for the `scoreboard players reset <targets>` bug (now covered by `tests/scoreboard/players/reset_all_objectives.mctest`); the packs are not generated by the harness.
- `bacap-grantall`: BACAP with `advancement grant DPTester1 everything` only (reward order bug, now `RewardOrderTests`).
- `mr-guns_plus_plus*`, `mr-vanilla-refresh*`: packs that do not load on 26.3; the `-norecipe` and `-sanitized` variants had content removed and were used for diagnosis only.
- `mr-dnt-tp`, `mr-incendium-tp*`: worldgen packs with a teleport into generated structures.
- `_counter`: harness self-test pack.
